## Sponsor technology contract

The final project must use AssemblyAI as a genuine runtime component of the voice-agent experience. The intended implementation uses AssemblyAI for the real-time voice interaction surface rather than as a decorative or incidental dependency.

## Current planned submission artifact

The project will demonstrate:

- real spoken input;
- AssemblyAI-powered voice interaction;
- structured proposed consequential action;
- real UCII identity verification through the supported public boundary;
- explicit UCII authority decision;
- denial when authority is absent;
- bounded delegated authority;
- successful execution while authority is valid;
- revocation;
- denial after revocation while identity remains verified;
- verifiable provenance/evidence;
- judge-facing visual proof.
